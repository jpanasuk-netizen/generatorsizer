What Size Generator Do I Need to Run a Space Heater?

Published October 2, 2026. Updated October 6, 2026.

Honda's radiant heater lists the same watts for start and run.

Quick answer: Champion lists a space heater at 750–1,500 watts with no separate start, and Honda lists a radiant heater at 1,300 running watts and 1,300 starting watts. Covering both takes a running rating that clears 1,500 W. A Honda EU2200i is rated 1,800 W with a 2,200 W maximum, which covers that heater.

How to size it

Add the running watts of every load that will be on together, then add the single highest starting surge (Generac; Honda). Generac notes that starting watts are often 2–3 times running watts, and that standby units should get a dealer survey.

Do not invent a start for the Champion row. Honda's radiant heater already sets start equal to run at 1,300 W. A gas furnace blower is a different load, with a 1/2 hp start as high as 2,350 W.

Worked example on this site's calculator

The home calculator adds running watts, keeps the single highest starting watts, then adds only the part of that start above that load's own running watts. Headroom defaults to 20%. The recommendation rounds up to the next 500 W.

Honda's radiant heater is 1,300 running watts and 1,300 starting watts. Extra = 1,300 − 1,300 = 0. Peak = 1,300. Then 1,300 × 1.20 = 1,560, which rounds up to 2,000 W recommended.

Champion lists a space heater at 750–1,500 watts and does not list a separate start. Treating the top of that band as both running and starting watts: extra = 0, peak = 1,500, and 1,500 × 1.20 = 1,800, which also rounds up to 2,000 W. A Honda EU2200i rated 1,800 W covers the 1,300 W and 1,500 W running figures. Its 2,200 W maximum is not what this walk is buying; the 20% step is what pushes the recommendation to 2,000 W.

FAQ

Does a space heater surge when it turns on?

Honda lists 1,300 W for both start and run. Champion lists 750–1,500 W and no separate start.

Will a Honda EU2200i run a 1,500 W heater?

Yes. 1,500 W is under the EU2200i rated output of 1,800 W. The maximum is 2,200 W.

Can I run two heaters?

Only if the combined running watts still clear the generator rating. One heater on Champion's chart can already be 1,500 W, and the EU2200i is rated 1,800 W.

Is a furnace fan the same as a space heater?

No. Honda lists a 1/2 hp furnace fan at 875 W running and 2,350 W starting. Use the furnace page for that motor.
