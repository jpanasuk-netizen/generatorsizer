What Size Generator Do I Need to Run a Pressure Washer?

Published October 2, 2026. Updated October 6, 2026.

Match the row to the washer you own, whether that is the horsepower line or the psi lines.

Quick answer: Honda lists a 1 hp pressure washer at 1,200 running watts and 3,600 starting watts, and Champion lists a 2,500 psi washer at 2,000–2,500 running watts and 4,000–5,000 starting watts. Covering both the 1 hp row and the 2,500 psi row takes a running rating that clears 2,500 W and a starting rating that clears 5,000 W. The Champion manual lists 5,000 W running and 6,250 W starting, which covers that start, while parallel EU2200i units reach only up to 4,400 W.

How to size it

Add the running watts of every load that will be on together, then add the single highest starting surge (Generac; Honda). Generac notes that starting watts are often 2–3 times running watts, and that standby units should get a dealer survey.

A 1,500 psi washer is the middle row: Champion lists 1,200–1,500 running watts and 2,400–3,000 starting watts. Honda's 1 hp start of 3,600 W is above that 1,500 psi start and below the 2,500 psi start of 5,000 W. Pick the row that matches the machine, then use the higher figure only when you want one generator that covers every row.

Worked example on this site's calculator

The home calculator adds running watts, keeps the single highest starting watts, then adds only the part of that start above that load's own running watts. Headroom defaults to 20%. The recommendation rounds up to the next 500 W.

Honda's 1 hp pressure washer is 1,200 running watts and 3,600 starting watts. Extra = 3,600 − 1,200 = 2,400. Peak = 1,200 + 2,400 = 3,600. Then 3,600 × 1.20 = 4,320, which rounds up to 4,500 W recommended.

Champion's 2,500 psi row at the top of each band is 2,500 running watts and 5,000 starting watts. Extra = 5,000 − 2,500 = 2,500. Peak = 2,500 + 2,500 = 5,000. Then 5,000 × 1.20 = 6,000 exactly, so the recommendation is 6,000 W. Two EU2200i units in parallel reach up to 4,400 W, which does not cover the 5,000 W start.

FAQ

What does Honda list for a 1 hp pressure washer?

1,200 running watts and 3,600 starting watts.

What does Champion list at 1,500 psi?

1,200–1,500 running watts and 2,400–3,000 starting watts.

What does Champion list at 2,500 psi?

2,000–2,500 running watts and 4,000–5,000 starting watts.

Will a 6,250 W starting rating cover the 2,500 psi row?

Yes. The manual lists 6,250 W starting and 5,000 W running. The row tops out at 5,000 W starting and 2,500 W running.
