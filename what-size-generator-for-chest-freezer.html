What Size Generator Do I Need to Run a Chest Freezer?

A freezer's running watts stay low. The start is the number to clear.

Quick answer: Champion lists a freezer at 100–500 running watts and 500–1,000 starting watts, and Honda lists an Energy Star fridge or freezer at 1,200 starting watts and 132–192 running watts. Covering both takes a running rating that clears 500 W and a starting rating that clears 1,200 W. A Honda EU2200i, rated 1,800 W with a 2,200 W maximum, covers that freezer start.

How to size it

Add the running watts of every load that will be on together, then add the single highest starting surge (Generac; Honda). Generac notes that starting watts are often 2–3 times running watts, and that standby units should get a dealer survey.

If the fridge is already running, add its running watts and still count only one start, the larger of the two. The larger start on these two rows is 1,200 W.

FAQ

How many running watts does a chest freezer use?

Champion lists 100–500 running watts. Honda's Energy Star fridge or freezer row lists 132–192 running watts.

What starting watts should I plan for?

Champion lists 500–1,000 starting watts for a freezer. Honda lists 1,200 starting watts for an Energy Star fridge or freezer. Cover 1,200 W.

Will a Honda EU2200i start a chest freezer?

The EU2200i maximum is 2,200 W and the rated output is 1,800 W. Both are above a 1,200 W start and a 500 W running load.

Should I add the fridge start and the freezer start together?

No. Generac sizes a generator from all running watts plus the single highest start. Here that start is 1,200 W.
