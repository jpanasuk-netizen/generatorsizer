What Size Generator Do I Need to Run a Table Saw?

Published October 2, 2026.

A saw's start is far above its running watts. Cover the higher chart.

Quick answer: Honda lists a 10-inch table saw at 1,800 running watts and 4,500 starting watts, and Champion lists a 10-inch table saw at 1,800–3,000 running watts and 3,600–6,000 starting watts. Covering both takes a running rating that clears 3,000 W and a starting rating that clears 6,000 W. The Champion manual lists 5,000 W running and 6,250 W starting, which covers that saw, while two Honda EU2200i units in parallel reach only up to 4,400 W.

How to size it

Add the running watts of every load that will be on together, then add the single highest starting surge (Generac; Honda). Generac notes that starting watts are often 2–3 times running watts, and that standby units should get a dealer survey.

Honda's running figure of 1,800 W matches the bottom of Champion's running range and equals the EU2200i rated output, but the start does not fit that generator's 2,200 W maximum. Keep other shop motors off while the saw starts, then add them only if their running watts still fit.

FAQ

What starting watts does a 10-inch table saw use?

Honda lists 4,500 W. Champion lists 3,600–6,000 W. Cover 6,000 W.

What running watts should I plan?

Champion goes up to 3,000 W. Honda lists 1,800 W. Cover 3,000 W.

Does a 6,250 W starting rating cover the saw?

Yes for these rows. The manual lists 6,250 W starting and 5,000 W running, against a 6,000 W start and 3,000 W running.

Can I start the saw and a compressor together?

Count only the higher start. A 1 hp compressor start is also 4,500 W, and the saw start can be 6,000 W, so the saw is the higher start if both are on the same chart.
