Rated (running) watts, starting or peak watts, fuel tank, and run time at the load the manufacturer stated. One row per published specification. This is not the appliance watt chart.

Quick answer: Size the loads on the calculator first. Then use a row whose rated watts cover the recommendation and whose starting watts cover the peak the calculator printed. The hours in the table are that manufacturer's test, not this site's fuel rule.

How to read the table

Each row links to the manufacturer page or PDF the cells came from. Those pages were opened on October 6, 2026. A cell says "not listed" when that page does not print the figure. This table does not fill the gap.

Where a specifications block and a feature sentence on the same page disagree, the table uses the specifications block. Honda's EU1000i specifications list a fuel tank of 0.55 gal. A feature line on that page says 0.6 gal. Champion's 201318 specifications list Gasoline Capacity 2.25 gal. The description says a 2.3-gallon tank. The rounded lines are not in the table.

A fuel cell says "not listed" when that specifications block does not name gasoline, propane, or natural gas. Honda's model-page specifications list a fuel tank capacity and do not name the fuel in that block. Generac's 7686-3 / 7686-4 / 7715-0 sheet lists the tank and the hours and does not name the fuel in the lines copied here. The 8929-0 sheet says the 12-hour runtime is when running on gasoline.

Propane tank sizes are copied from the product description on the same page when the specifications table lists a gasoline capacity and a propane run time but no propane tank capacity. Champion 201176 lists natural-gas watts and does not list a natural-gas tank or a natural-gas run time.

Two Generac GP8000E sheets are separate rows. Model 7686-3 / 7686-4 / 7715-0 lists 15 hours at 25% of rated load and 10 hours at 50% of rated load. Model 8929-0 lists 15.5 hours at 25% and 12 hours at 50%. This page does not average them.

Westinghouse's WGen11500DFc introduction says the generator runs on gasoline, propane, or natural gas. The specifications table on that page lists gasoline and propane watts and does not list natural-gas watts or a natural-gas run time, so there is no natural-gas row.

The Predator row is Harbor Freight item 71358, from that item's owner's manual. It is not the older 59137 manual, which prints a different tank, and it is not a product-page line that says "over 11 hours."

Worked example with the calculator

The homepage calculator adds two loads when the page opens: Refrigerator (Energy Star, 20 cu ft) at 150 running watts and 600 starting watts, and LED lights (whole home) at 80 running watts and 80 starting watts. Headroom on the form is 20%. Those watt figures are the calculator's presets, not a row in the table above.

  • Running total = 150 + 80 = 230 W.
  • The largest starting watts are the refrigerator's 600 W. Extra surge = 600 − 150 = 450 W.
  • Peak = 230 + 450 = 680 W.
  • 680 × 1.20 = 816. The calculator rounds up to the next 500 W, so the button prints 1,000 watts recommended.

The EU2200i specifications list 1800W rated and 2200W max. Both are above the 680 W peak and above the 1,000 W recommendation from these inputs. That is a comparison of two published figures. It is not a test of the EU2200i on this load.

The same form defaults the tank to 4 gallons. The button's gasoline line is recommended watts ÷ 7,000, so 1,000 ÷ 7,000 gallons per hour. On that 4 gallon tank, 4 ÷ (1,000 ÷ 7,000) = 28.0 hours. The button prints 28.0 h. That 28.0 hours is this site's rule. It is not the EU2200i line of 3.2hr at rated load or 8.1 hrs at 1/4 load on a .95 gal tank.

Run a generator outdoors only, at least 20 feet from the house, never inside, including a garage with the door open (CPSC). A longer tank time is not permission to move it closer. Connecting a generator to household circuits takes a licensed electrician and a permit where local code requires one.
