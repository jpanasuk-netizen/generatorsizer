What Size Generator Do I Need to Run a Refrigerator and Freezer?

Add both running loads, then add only the larger compressor start.

Full breakdown: refrigerator and freezer sizing.

Quick answer: Honda lists an Energy Star fridge at 132–192 running watts and 1,200 starting watts, Champion lists a fridge at 150–400 running watts and 800–1,200 starting watts, and Champion lists a freezer at 100–500 running watts and 500–1,000 starting watts. Add the fridge and freezer running watts, then add only the highest start, which on these charts is 1,200 W. A Honda EU2200i rated at 1,800 W, with a 2,200 W maximum, covers that 1,200 W start, and both running ranges sit below that rated output.

How to size it

Add the running watts of every load that will be on together, then add the single highest starting surge (Generac; Honda). Generac notes that starting watts are often 2–3 times running watts, and that standby units should get a dealer survey.

Honda's power-management example uses different figures than the wattage-guide rows above. It puts a fridge at 1,600 W start and 200 W run, a 1/4 hp furnace fan at 1,600 W start and 600 W run, 5 lights at 300 W, a TV at 300 W, and a microwave at 1,500 W, and it states that this comes to 1,400 W continuous with a 1,600 W maximum start, sized to a 3,000 W generator. That example is a larger stack than a fridge plus a freezer, which is why the same method still lands on the EU2200i for the two appliances alone.

FAQ

Do both compressors start at the same time?

Plan for one start. Generac says to add every running watt, then only the highest starting surge. On these charts that surge is 1,200 W.

Which running watts do I add?

Use the row that matches each appliance. A Champion fridge can be as high as 400 W running and a freezer as high as 500 W running. Honda's Energy Star running range is 132–192 W.

Is the 1,600 W fridge in Honda's example the same as the wattage guide?

No. The wattage guide lists 1,200 W start and 132–192 W run. The power-management example lists a fridge at 1,600 W start and 200 W run. Keep those sources separate.

Can one EU2200i carry both?

Yes for the charts on this page. The highest start is 1,200 W and the EU2200i maximum is 2,200 W, with 1,800 W rated.
