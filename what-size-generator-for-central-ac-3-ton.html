What Size Generator Do I Need to Run a 3-Ton Central Air Conditioner?

Published October 2, 2026.

Tonnage sets the watts. Use the chart row that matches the outdoor unit.

Quick answer: Champion lists a 3-ton central air conditioner at 3,000–3,500 running watts and 5,000–6,000 starting watts. Covering that row takes a running rating that clears 3,500 W and a starting rating that clears 6,000 W. The Champion manual lists 5,000 W running and 6,250 W starting, which covers the 3-ton row, while a Honda EU2200i maximum of 2,200 W does not.

How to size it

Add the running watts of every load that will be on together, then add the single highest starting surge (Generac; Honda). Generac notes that starting watts are often 2–3 times running watts, and that standby units should get a dealer survey.

The 2-ton row on the same chart is 2,000–2,500 running watts and 3,500–4,500 starting watts. The manual's 6,250 W starting rating covers that 4,500 W start. Parallel EU2200i output of up to 4,400 W does not. The condenser is hardwired, so use a transfer switch or interlock installed by an electrician. See the transfer switch sizing guide.

Generac recommends a dealer survey before you buy a standby unit for this kind of motor.

FAQ

Can the Champion 5,000 W generator run a 3-ton AC?

Its published ratings do. The manual lists 5,000 W running and 6,250 W starting. Champion's 3-ton row tops out at 3,500 W running and 6,000 W starting. That is the air conditioner alone.

Will two EU2200i generators in parallel run a 3-ton AC?

Parallel output is up to 4,400 W. The 3-ton start is 5,000–6,000 W, which is higher.

What does a 2-ton system need?

Champion lists 2,000–2,500 running watts and 3,500–4,500 starting watts. The 6,250 W starting rating covers that row.

Where is the 4-ton figure?

On the 4-ton page. Champion lists that row at 4,000–5,000 running watts and 6,500–8,000 starting watts, which is above the 6,250 W starting rating.
