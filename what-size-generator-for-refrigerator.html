What Size Generator Do I Need to Run a Refrigerator?

Published October 2, 2026.

The compressor start, not the steady draw, is the figure that picks the generator.

Quick answer: Honda lists an Energy Star fridge at 132–192 running watts and 1,200 starting watts, and Champion lists a fridge at 150–400 running watts and 800–1,200 starting watts. Covering both charts takes a running rating that clears 400 W and a starting rating that clears 1,200 W. A Honda EU2200i is rated 1,800 W with a 2,200 W maximum, which covers that start and those running watts.

How to size it

Add the running watts of every load that will be on together, then add the single highest starting surge (Generac; Honda). Generac notes that starting watts are often 2–3 times running watts, and that standby units should get a dealer survey.

Use the higher running figure while the compressor is on, then add the 1,200 W start once. A second appliance only changes the size if its own start is higher than that 1,200 W figure or its running watts push the total past the generator rating you picked.

FAQ

Can a Honda EU2200i run a refrigerator?

Yes on these charts. The highest fridge start listed is 1,200 W, and the highest running figure is 400 W. The EU2200i is rated 1,800 W with a 2,200 W maximum.

Why do the Honda and Champion fridge figures differ?

They publish different ranges. Honda is 132–192 W running and 1,200 W starting for an Energy Star fridge or freezer. Champion is 150–400 W running and 800–1,200 W starting. Size to the higher number in each column.

Do I add a surge on top of the chart?

No. Generac says starting watts are often 2–3 times running watts, and the charts already give the start. Use the listed start, not a second multiplier.

What changes if a freezer is running too?

Add the freezer's running watts, then keep only the highest start. On these charts that start is still 1,200 W. The combined question has its own page.
