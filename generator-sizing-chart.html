Worked example: the garage door opener

The home calculator adds running watts, keeps the single highest starting watts, then adds only the part of that start above that load's own running watts. Headroom defaults to 20%. The recommendation rounds up to the next 500 W.

Honda's garage door opener is 720 running watts and 1,420 starting watts. Extra starting watts = 1,420 − 720 = 700. Peak = 720 + 700 = 1,420. With 20% headroom, 1,420 × 1.20 = 1,704, which rounds up to 2,000 W recommended. A Honda EU2200i is rated 1,800 W with a 2,200 W maximum, which covers the 720 W run and the 1,420 W start. Buying for 720 W running only misses the start. The same walk is on what size generator for a garage door opener.

A combined refrigerator and freezer list, which is more than one row, is on refrigerator and freezer and on the longer fridge and freezer guide.

Run the generator outdoors only, at least 20 feet from the house, never inside, including a garage with the door open (CPSC). Connecting it to a building takes a licensed electrician and a permit where local code requires one.
